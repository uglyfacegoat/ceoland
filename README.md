# CEOMENTALITY · ceowallet

Фронтенд по [Figma 143:908](https://www.figma.com/design/zUFWKkkM6KeX3hCWcg4kLK/CEOMENTALITY?node-id=143-908), с согласованными изменениями. TypeScript, Vite, обычные HTML/CSS; без сторонних runtime-пакетов. Бэкенд и платёжная интеграция не входят в проект.

## Запуск

Node.js 24 LTS: сборка и тесты используют встроенный запуск TypeScript.

```powershell
cd website
npm ci
npm run dev
```

Основная страница — `/`, каталог экранов — `/preview`. Для телефона в той же локальной сети: `npm run dev -- --host 0.0.0.0`.

```powershell
npm run typecheck
npm test
npm run build
npm run preview
```

`build` создаёт `website/dist`: готовый HTML для 15 маршрутов, страницу 404, CSS/JS, изображения, robots.txt и sitemap.xml. Пока домен не выбран, это сборка для просмотра с закрытой индексацией. Перед публикацией задайте `VITE_SITE_URL` и выполните `npm run build:release`; подробности — в инструкции по SEO ниже.

Для Vercel добавлен `vercel.json` в корне репозитория. При импорте оставьте **Root Directory: `./`**, выберите **Node.js 24.x**. Установка, сборка и каталог публикации заданы в файле. Порядок настройки домена и проверки после деплоя — в [инструкции](docs/seo-and-deployment.md#vercel).

## Что работает

- Лендинг, мобильное меню, переходы к разделам, адаптация от 320 до 3840 px.
- **ceowallet, 2 990 ₽**. Белый и чёрный цвета, четыре фото белого и одно фото чёрного. Галерея переключается кнопкой, стрелками клавиатуры и свайпом.
- Раздельные позиции цветов в корзине, количество, удаление и сохранение. Корзина предыдущей версии автоматически переводится в белый вариант.
- Состав заказа с цветами, форма контактов и согласия. Ошибки полей показаны в интерфейсе, без браузерных всплывашек. Значения сохраняются при ошибке.
- Демонстрация проверки кода и заявки; честное состояние неподключённой оплаты.
- Выбор худи, кепки и футболки в футере переключает блок «забрать своё». Это концепты без цены и покупки. Возврат сохраняет выбранный цвет кошелька.
- Таймер до **31 декабря 2026, 00:00 по Москве**. Настройка в `website/src/drop.ts`; перелистывание отключается при reduced motion, отсчёт приостанавливает обновления вне экрана.
- Скрытые полосы прокрутки; колесо, касания и клавиатура продолжают прокручивать сайт.

Код **CM-DEMO-2026** — только для просмотра. Заявки и платежи не отправляются. В localStorage хранятся только версия корзины, SKU и количество; контакты и коды не сохраняются. Документы, реквизиты и контакты ожидаются от заказчика.

## Сохранённые 3D-исходники

Сохранены 72 файла моделей/материалов и их версий, библиотека текстур, архив `ceo-3d-assets.zip`. Их SHA-256 проверяются по [реестру](docs/models-preserved.json). Исходные пути внутри assets, blender, references, previews и revisions сохранены ради зависимостей сцен. Сайт эти файлы не загружает. Старые сайт, видео-прототип, рендеры и скрипты ранее удалены по запросу; история Git и настройки LFS сохранены.
