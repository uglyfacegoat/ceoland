# CEOMENTALITY — публичный сайт

Статический HTML/CSS/JavaScript без зависимостей сборки. Локальные шрифты Inter и Roboto Mono, фотографии и графика из Figma.

## Запуск и проверка

- `npm run dev` — http://localhost:4173.
- `npm run build` — статическая сборка в `dist/`, используется Vercel.
- `npm test` — проверки загрузочного экрана и производительности типографических анимаций.
- `npm run test:browser` — 31 публичный экран на ширинах 320, 375, 390, 430, 700, 768 и 1440 px, а также сценарии форм, корзины и клавиатуры. Нужны Playwright и Chrome; пути задаются через `PLAYWRIGHT_MODULE` и `CHROME_PATH`, адрес сайта — `SITE_URL`. По умолчанию используется Playwright из локального Codex runtime и Chrome на macOS. Перед проверкой запустите сайт.

## Экраны

Главная — `index.html`. Остальные страницы — `app.html?screen=...`. Каждый адрес открывается напрямую на статическом хостинге и поддерживает обычную историю браузера.

Все экраны для ревью: **`app.html?screen=screens`**. Каталог открывает по фото или названию полноценную карточку товара. Основной цвет CEOWALLET — белый, цена — **2 990 ₽**. Видимые габариты чёрного и белого вариантов выровнены через `wallet-media.css`, исходные фотографии не изменены. Тёмный кобальт: `#2451B2`. Анимированные стрелки на главной перенесены на место удалённой кнопки просмотра. Пять шагов покупки и вступления связаны четырьмя стрелками; на мобильном они растут вместе с текстом. Блок «Твой новый круг» сохраняет форму билета, а фотография приглашения заменена типографической композицией «СВОИ ЛЮДИ.» и серийным номером.

| Раздел | screen |
| --- | --- |
| Линейка и товары | `objects`, `wallet`, `wallet-white`, `nfc`, `next-item` |
| Покупка | `access`, `code-error`, `cart`, `cart-empty`, `checkout`, `checkout-validation`, `payment` |
| Статусы оплаты и заказа | `processing`, `payment-failed`, `thank-you`, `order` |
| Вступление | `join`, `application`, `application-received`, `membership-confirmed` |
| Запрос кода | `purchase-application`, `purchase-received` |
| Навигация и помощь | `menu`, `faq`, `contact`, `contact-received`, `loading` |
| Документы | `privacy`, `agreement`, `purchase-terms`, `company` |

Админка исключена из этой реализации. Приватная анкета не связана с публичной кнопкой «Как вступить»: публичный экран объясняет получение объекта и QR, а адрес `application` предназначен для будущего QR-приглашения.

## Интерфейс и интеграции

Это реализация экранов сайта, без сервера заказов и платежей. В обычном режиме формы валидируют данные и сообщают, что отправка недоступна. Произвольный код не открывает покупку; платёжные реквизиты не собираются. Страницы подтверждений без деморежима не утверждают, что заказ оплачен или заявка одобрена.

Для проверки полного сценария откройте галерею экранов: ссылки включают `demo=1`, сверху постоянно виден индикатор предпросмотра. Демо-код — **`CEO-DEMO-2026`**. Сценарий: карточка → код → корзина → оформление → оплата → ожидание → подтверждение. В корзине работают количество, удаление и сохранение в пределах вкладки. Формы проверяют обязательные поля, email, телефон и согласия. Демоданные и демокорзина отделены от обычного режима; отправок и списаний нет.

Для запуска продаж нужно подключить серверную проверку и резервирование кодов, отправку заявок, расчёт доставки, защищённые ссылки статусов и платёжный сервис. Доступ по QR и статусы членства также проверяются сервером. Клиентский параметр `demo` — только предпросмотр, не авторизация.

Тексты документов перенесены из макета. В нём пока оставлены незаполненные сведения продавца, условия доставки и части окончательной редакции документов. Они не выдуманы в коде.

## Дизайн и анимации

Figma: https://www.figma.com/design/HPZlb9wLIFzr5NvphRrUbE/CEOMENTALITY-LANDING?node-id=0-1

`design/screens.json` содержит карту публичных desktop/mobile фреймов. На Education-плане Figma часть запросов достигла лимита: мобильные privacy/agreement и desktop «Как вступить» адаптированы по полученной парной версии и общим компонентам. Остальные публичные пары получены полностью.

`site.js` содержит общие шапку, навигацию, формы, галереи, статусы и маршрутизацию. `site.css` задаёт адаптивную вёрстку. `documents.js` хранит тексты документов. Главная использует исходные `styles.css`, `main.js` и загрузчик.

Типографические фигуры состоят из HTML-текста; данные — `assets/type-objects.js`, анимации — `typography.js` и `typography.css`. Они останавливаются вне экрана, в скрытой вкладке и при системной настройке уменьшения движения. Фотографии и SVG локальные, временные Figma URL для работы сайта не нужны.
