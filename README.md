# CEOMENTALITY — публичный сайт

Актуальный сайт находится **в корне репозитория**. HTML/CSS/JavaScript без runtime-зависимостей и без фреймворка сборки. Главная — `index.html`; внутренние экраны — `app.html?screen=...`. Админки и бизнес-бэкенда здесь нет.

## Запуск

Node.js 22+.

```sh
npm ci
npm run dev
```

http://localhost:4173. `npm run build` создаёт чистый `dist/`. Vercel: Root Directory `./`, конфигурация в `vercel.json`. Деплой содержит только сайт и его ресурсы, без исходников дизайна, тестов и документации.

## Передача бэкендеру

Начать с **[инструкции по подключению](docs/backend-handoff.md)** и **[OpenAPI-контракта](docs/openapi.json)**.

`integration/api.js` уже подключён к формам, кодам, заказам и оплате. В `runtime-config.js` сейчас выбран `offline`: API не подключён в настройках этой версии, данные форм не отправляются. После реализации контракта бэкендер включает `mode: 'api'`, настраивает same-origin `/api/v1`, платёжные origins и выключает предпросмотр. Цена, доставка, права и статусы в этом режиме приходят с сервера.

Фронтенд не собирает данные банковских карт и не сохраняет контакты в браузерное хранилище. Создание заказа происходит после отдельного подтверждения серверного расчёта с доставкой. Оплата открывается на разрешённом HTTPS-origin провайдера. Возврат с оплаты не считается её подтверждением.

## Проверки

```sh
npx playwright install chromium
npm test
npm run test:browser
# всё вместе:
npm run check
```

`test:browser` сам собирает сайт и поднимает временный статический сервер. `SITE_URL` позволяет проверить уже запущенный сайт. `PLAYWRIGHT_CHANNEL=chrome` использует установленный Chrome; `CHROME_PATH` — явно заданный исполняемый файл. Снимки и отчёт — в `ARTIFACT_DIR`, по умолчанию в системной временной папке `ceoland-tests`. CI запускает проверки на Linux и сохраняет артефакты.

Тесты покрывают 26 экранов на семи ширинах, фото и типографику, формы, корзину, клавиатуру, отказ API, идемпотентный повтор, расчёт доставки, создание заказа, переход к провайдеру, реальные состояния заказа по HTTP-мокам, QR-доступ и разграничение демо. Моки не заменяют приёмку реального сервера.

## Экраны

Для визуального ревью: `app.html?screen=screens`, если `previewEnabled: true`. Ссылки из галереи включают `demo=1`; сверху видна пометка предпросмотра. Демо-код `CEO-DEMO-2026`. Демо не отправляет запросы API и не списывает деньги.

| Каталог | `objects`, `wallet`, `wallet-white`, `nfc`, `next-item` |
| Покупка | `access`, `code-error`, `cart`, `cart-empty`, `checkout`, `checkout-validation`, `payment` |
| Заказ | `processing`, `payment-failed`, `thank-you`, `order` |

| Запрос кода | `purchase-application`, `purchase-received` |

Основной товар — белый CEOWALLET, витринная цена 2990 ₽. Габариты фотографий выровнены через `wallet-media.css`. Тизеры NFC CARD и NEXT ITEM не продаются. На главной пять шагов, квадрат из букв с вертикальной анимацией скрыт на мобильном. Анимации учитывают reduced motion и видимость вкладки.

## Структура

- `site.js`, `site.css` — внутренние экраны и клиентские сценарии.
- `main.js`, `styles.css`, `index.html` — главная.
- `integration/`, `runtime-config.js` — контракт подключения.
- `documents.js` — рабочая юридическая редакция от 20.10.2026, подтверждённые сведения продавца. Вопросы к реализации и незавершённые сведения находятся только в `docs/legal-readiness.md`. Для согласия `data-consent` используется параметр `purpose=contact`, `purpose=purchase-application` или `purpose=application`. До запуска требуется завершить внутренний перечень и утвердить окончательные тексты.
- `assets/`, `typography.*`, `loader.*` — локальные изображения, шрифты и анимации.
- `design/` — карта фреймов и четыре визуальных ориентира, не входят в деплой.
- `docs/` — актуальная передача и сведения об архиве.

Макет: [CEOMENTALITY LANDING](https://www.figma.com/design/HPZlb9wLIFzr5NvphRrUbE/CEOMENTALITY-LANDING?node-id=0-1). Сайт не зависит от временных URL Figma. Старый сайт и 3D-архив исключены из рабочей ветки: [как восстановить](docs/archive.md).

## Иконки сайта

`favicon.svg` и PNG/ICO используют контур C из исходного `assets/wordmark.svg`, без подмены шрифта. Набор включает ICO 16/32/48/256, PNG 96 для браузеров/поиска, Apple 120/152/167/180, Android/PWA 192/512, maskable 512, одноцветный Safari pinned icon и Windows tile. На обеих HTML-страницах подключены одинаковые метаданные.

Для обновления экспортов: `npm run icons` (локально требуется ImageMagick 7). Исходный знак берётся из первого контура `assets/wordmark.svg`; настройки цвета и безопасных полей — в `scripts/generate-icons.mjs`. Готовые изображения коммитятся, сборка не требует ImageMagick. `site.webmanifest` задаёт имя, стартовый адрес, область и режим установки. Service worker не добавлен: кеширование заказов, платежей и юридических редакций требует отдельного решения.

## Юридические редакции и подготовка РКН

Единый перечень подтверждённых сведений, карта данных/получателей, заготовка полей уведомления и оставшиеся задачи — [docs/legal-readiness.md](docs/legal-readiness.md). Документы остаются рабочей редакцией до подтверждения владельцем и проверки реальных интеграций.

`npm run legal` создаёт HTML/TXT без JavaScript и SHA-256 в `legal/<revision>/`, а также общий `legal/index.html`. Уже сохранённую редакцию генератор не перезаписывает другим текстом; при изменении источника задаётся новая дата редакции или порядковый суффикс в пределах одного дня, например `2026-10-20.1`. `npm run build` проверяет/обновляет экспорты перед сборкой. Сервер должен независимо хранить проверенную редакцию и доказательства согласия; передаваемые клиентом `X-Legal-Revision` / `X-Legal-Purpose` этого не заменяют.
