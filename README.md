## Типографика и графика

Все восемь типов фигур (поле слов, встречные стрелки, ромб, шеврон, кольца, плетёная подпись, вопросительный знак, треугольник) состоят из настоящего HTML-текста. Координаты, цвета и размеры букв для desktop/mobile сохранены из Figma в `assets/type-objects.js`. Рендерер и анимации — `typography.js`, стили — `typography.css`. PNG-подмен этих фигур нет.

Анимации работают только для видимых фигур, останавливаются в скрытой вкладке и при системной настройке уменьшения движения. Кольца вращаются в противоположных направлениях, остальные фигуры анимируют строки или отдельные буквы.

Логотип, штрихкоды, линии и стрелки подключены оригинальными локальными SVG. Растровыми остаются только фотографии товаров и изображение карты. Все ресурсы страницы локальные; Figma не требуется при просмотре. Референсы в `design/reference` не используются на странице.

## Сборка и публикация

`npm run build` создаёт статический лендинг в `dist/`. Для Vercel используется корень репозитория и настройки из `vercel.json`.

Хиро: бесконечный поток слов разного размера с искривлением строк и отталкиванием букв от курсора. Ромб анимирует строки с увеличенным разъездом.

Предыдущий сайт сохранён в `website/`, его описание — в `docs/previous-site.md`.

Хиро создаёт только активную версию экрана. Непрерывное движение выполняет Web Animations API; JavaScript обрабатывает лишь взаимодействие с курсором. `npm test` проверяет ограничение количества букв, отсутствие измерений каждой буквы и остановку вычислений после взаимодействия.
