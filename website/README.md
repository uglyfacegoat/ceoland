# CEOMENTALITY — первый экран

Vite, TypeScript и Three.js. Текст находится в HTML, архитектурный фон — в CSS. Картхолдер и два блока подиума — 3D-меши с освещением, запечённым в Blender. Контрольная композиция: 1599 × 984; предусмотрены адаптивные размеры.

```powershell
npm ci
npm run dev -- --port 5173 --strictPort
npm run build
```

Локальный адрес: http://127.0.0.1:5173. Сборка выполняет проверку TypeScript и создаёт `dist/`.

- `index.html` — содержание.
- `src/style.css` — типографика, фон и адаптивная вёрстка.
- `src/product-scene.ts` — загрузка сцены, камера, изменение размеров, освобождение WebGL-ресурсов.
- `public/models/hero-scene.glb` — композиция с запечёнными тенями, KHR_materials_unlit и WebP.
- `public/models/cardholder.glb` — отдельная модель с PBR-материалами.
- `public/models/key.glb` — ключ; в первом экране не загружается.

Canvas перерисовывается при изменении размеров и восстановлении WebGL-контекста. Постоянного цикла анимации нет. Ошибки загрузки показываются явно. Кнопки пока отключены по указанию пользователя.

Для изменения освещения откройте `../blender/hero-scene.blend`, пересчитайте атласы через `../scripts/bake_hero.py` и замените GLB. Положение предметов относительно света фиксировано.
