# Удалённые из рабочей ветки материалы

Перед подготовкой к API в main одновременно лежали текущий сайт, прежний проект `website/`, документация к нему и 3D-архив. Они не участвовали в текущей сборке и создавали неоднозначность при передаче.

Архивная версия: commit **e52a80859c0b88edfa04fc632f038e760a48715e**, до очистки. История не переписана.

Удалены из рабочей версии:

- `website/` — прежний сайт на другом макете и его зависимости.
- `blender/`, `revisions/`, `references/`, `previews/website-archive/`, `assets/models/`, `ceo-3d-assets.zip` — неиспользуемые в сайте модели, сцены, текстуры и резервные версии.
- Прежние `docs/*`, описывающие старый TypeScript/Vite-проект. Актуальная инструкция создана заново.
- Два неиспользуемых SVG `assets/imgGroup.svg`, `assets/imgGroup1.svg`.

Для просмотра исходного состояния без изменений текущей ветки:

```sh
git worktree add --detach ../ceoland-archive e52a80859c0b88edfa04fc632f038e760a48715e
```

3D-файлы в Git использовали LFS. В очищаемом checkout были **LFS-указатели, а не бинарные модели**. Для восстановления моделей нужен Git LFS и доступ к прежнему LFS-хранилищу (`git lfs pull` в архивном worktree). Очистка не удаляла объекты из удалённого LFS и не переписывала Git-историю; наличие удалённых бинарных объектов отдельно не проверялось.

Локальная копия удаляемого checkout сохранена вне репозитория в `~/ceoland-archive-20260923/`. Для 3D она также содержит только имевшиеся LFS-указатели. Она не требуется для сборки и не публикуется.
