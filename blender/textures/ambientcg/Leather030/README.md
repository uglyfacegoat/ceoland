# Leather030

Source: [ambientCG Leather030](https://ambientcg.com/view?id=Leather030).
License: [CC0](https://docs.ambientcg.com/license/).

This is ambientCG's procedural pebbled material, not a scan of the client product.
The retained original 2K PNG maps supply displacement and roughness only;
`Leather030.png` is the source preview. Source colour and normal maps are unused.
The authored 110 mm UV repeat and 90 µm displacement scale are artistic estimates.
White leather and navy ink colours are authored separately in `scripts/client_relit.py`.
