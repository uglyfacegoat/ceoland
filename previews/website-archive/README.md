# Previous website assets

These original images and models are preserved outside the Vite public directory.
They are no longer shipped with the photo-first website. The desktop campaign
and collection originals remain inputs to `website/scripts/prepare-images.mjs`.
Current delivery assets are in `website/public/images/editorial/`.

The native Blender cardholder/key masters are retained in their existing
`previews/client-relit/` and `previews/key-relit/` directories. Key animation is
deferred; the current page uses one newly generated static editorial frame.
